# Results

Generated by `analysis/make_report.py` from the raw result files in this folder. Do not edit by hand.

**Definitions.** *Tokens / item* = prompt + completion tokens summed over every model call of an item (an agent re-sends its whole context at each step). *Reasoning* tokens are part of completion tokens. Truncated items (token limit reached) count as failures. *Tokens per correct item* = all tokens of the condition ÷ number of correct items, the price-independent cost of one *successful* task. 95% intervals: Wilson for accuracy; percentile bootstrap over items (10,000 resamples, seed 0) for means; contrasts resample the shared items jointly (paired).
